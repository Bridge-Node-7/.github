# Security policy

## Supported versions

Only the latest tagged GitHub Release of each public repository is supported for security fixes, unless a repository README says otherwise.

## Reporting a vulnerability

Please report security issues privately. Prefer GitHub Private Vulnerability Reporting when enabled on the repository. Otherwise contact the project through the brand security contact listed in the Bridge-Node-7 profile `SECURITY.md`.

Do not include personal data or production secrets in the report beyond what is required to reproduce the issue.

## Public discussion

Do not open public issues for unfixed vulnerabilities.
